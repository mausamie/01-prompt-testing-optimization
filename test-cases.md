# Prompt Test Cases version:1.0

## Purpose
These test cases are designed to test prompt against each scenario so that weaknesses can be identified consistently.

## Test Case 1 — General AI Topic
**Input/Scenario:**
Create an Instagram caption about the benefits of artificial intelligence for students.

**Expected Result:**
* The caption should be relevant to students.
* It should explain benefits of AI.
* It should be clear and engaging.
* It should be suitable for Instagram.

**Evaluation Criteria:**
* Relevance
* Clarity
* Engagement
* Student-focused content
  
## Test Case 2 — Beginner Audience
**Input/Scenario:**
Create an Instagram caption explaining generative AI to students who are new to AI.

**Expected Result:**
* The explanation should use simple language.
* Technical jargon should be minimized.
* The caption should be easy for beginners to understand.
* It should remain engaging.

**Evaluation Criteria:**
* Simplicity
* Clarity
* Beginner suitability
* Relevance

## Test Case 3 — Specific AI Topic
**Input/Scenario:**
Create an Instagram caption about how students can use ChatGPT for studying.

**Expected Result:**
* The caption should focus specifically on studying.
* It should provide useful ideas.
* It should avoid unrelated AI information.
* It should be appropriate for students.

**Evaluation Criteria:**
* Topic focus
* Usefulness
* Relevance
* Accuracy

## Test Case 4 — Engagement-Focused Content
**Input/Scenario:**
Create an Instagram caption about AI that encourages students to comment and share their opinions.

**Expected Result:**
* The caption should encourage interaction.
* It should include a clear call to action.
* The tone should be suitable for social media.
* The question or CTA should be relevant to students.

**Evaluation Criteria:**
* Engagement
* Call to action
* Relevance
* Social media suitability

## Test Case 5 — Short Caption
**Input/Scenario:**
Create a short Instagram caption about AI for students in approximately 30–40 words.

**Expected Result:**
* The caption should stay close to the requested length.
* It should communicate one clear idea.
* It should remain relevant to students.
* It should be concise and engaging.

**Evaluation Criteria:**
* Length control
* Clarity
* Relevance
* Conciseness

## Testing Rule
The original prompt will be evaluated against all five test cases before optimization. The optimized prompt will then be tested against the same five scenarios. Using the same test cases allows the original and optimized prompts to be compared fairly.

# Test Case 1
## Prompt
You are a social media content writer specializing in educational technology content.
Create an Instagram caption for university students who are interested in learning about artificial intelligence.

### Instructions
* Focus on the specific AI topic provided by the user.
* Use simple, clear, and beginner-friendly language.
* Keep the tone friendly, informative, and engaging.
* Avoid unnecessary technical jargon.
* Keep the caption concise.
* Include a strong opening hook.
* End with a relevant call to action that encourages students to interact.
* Include 3–5 relevant hashtags.

### Output Format
Use this structure:
**Hook:** One attention-grabbing opening sentence.
**Caption:** A concise explanation or message related to the topic.
**Call to Action:** One question or action encouraging engagement.
**Hashtags:** 3–5 relevant hashtags.

### Topic: Benefits of artificial intelligence for students
