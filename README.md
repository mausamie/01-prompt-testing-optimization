# Prompt Testing & Optimization System

## Project Overview
This project demonstrates the process of creating, testing, evaluating and optimizing an AI prompt.

# Objective

To improve the quality, relevance, consistency, and instruction-following
of AI-generated social media content through systematic prompt testing.

## Tools Used
- GitHub
- Markdown
- Open Ai(chatgpt)

## Methodology

1. Create an initial prompt.
2. Design multiple test cases.
3. Test the original prompt.
4. Identify weaknesses.
5. Create an optimized prompt.
6. Retest using the same test cases.
7. Compare the results.
8. Document the improvements.
